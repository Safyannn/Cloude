# مجلد الوسائط (الصور والفيديو) — Media drop-in guide

الموقع جاهز ويعمل الآن. كل صورة لها **مكان محدد ومسمّى مسبقًا**. عند غياب الصورة
تظهر بطاقة أنيقة بشعار الخدمة مؤقتًا؛ بمجرد وضع الملف بالاسم الصحيح **تظهر الصورة
تلقائيًا** دون تعديل أي كود.

The site works right now. Every image has a fixed, pre-named slot. Until a file is
present an on-brand placeholder tile shows; drop the file in with the exact name
below and it appears automatically — no code changes.

## أين تضع الملفات — Where files go

| المسار / Path | الملف المتوقع / Expected file | يظهر في / Used on |
|---|---|---|
| `hero/` | `hero-video.mp4` + `hero-fallback.jpg` | خلفية الهيرو (الرئيسية) |
| `01-iron-gates/` … `12-welding-services/` | `img-1.jpg` … `img-4.jpg` (+ `video.mp4`) | خدماتنا + أعمالنا |
| `team/` | `workshop-1.jpg`, `team-1.jpg` | الرئيسية + من نحن |
| `brand/` | `logo.png`, `favicon.png` | الشعار + أيقونة المتصفح |
| `gallery/` | صور إضافية للمعرض (اختياري) | — |

الصفحات تشير حاليًا إلى `img-1.jpg` و`img-2.jpg` في كل مجلد خدمة. أضف `img-3/4` إن
رغبت بلاحقًا في توسيع المعرض.

## نصائح مهمة — Tips

- **الأبعاد المقترحة:** بطاقات الخدمات 4:3، معرض الأعمال مربّع 1:1، صورة "من نحن/الورشة"
  عمودية 4:5. الهيرو أفقي عريض (1920×1080 أو أكبر).
- **الضغط قبل الرفع:** صغّر حجم الصور (استخدم TinyPNG أو Squoosh) وابقِ الفيديو تحت
  بضعة ميغابايت ليكون التحميل سريعًا على الجوال.
- **صيغ مفضّلة:** `.jpg` للصور، `.mp4` (H.264) للفيديو، `.png` شفاف للشعار.
- أسماء الملفات حسّاسة لحالة الأحرف — استخدم الأحرف الصغيرة كما هي مكتوبة أعلاه.

> ملاحظة: مجلدات الوسائط أُنشئت فارغة عمدًا (بها ملف `.gitkeep` فقط). لم تُرفق أي
> صور مع هذا التسليم — راجع "media collection brief" لجمعها ثم ضعها هنا.
