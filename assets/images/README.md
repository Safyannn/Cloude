# 📸 Heliotrope Safety — Image Upload Guide

Apni asli images yahan upload karein. **Har image ka naam bilkul wahi rakhein**
jo neeche diya hai (extension `.png` / `.jpg` bhi same rakhein), warna website
image nahi pakregi.

> Tip: GitHub par upload karte waqt agar same naam ki file dobara upload karein
> to woh purani placeholder ko **replace** kar deti hai. Bas.

---

## 1) Brand images — folder: `assets/images/`

| Kya | File naam (exact) | Recommended size |
|---|---|---|
| 🏷️ Company logo (header + footer) | `logo.png` | 200×200 (square, transparent PNG best) |
| 🧤 Hero showcase (13 gloves ek saath) | `gloves-showcase.png` | 1200×960 |
| 📜 Certification strip | `certification-strip.png` | 600×170 |
| ♻️ REACH badge | `reach-logo.png` | 300×300 |
| 🏭 Factory ki photo | `factory.jpg` | 1200×800 |

Optional supporting photos (agar badalni hon):
`warehouse-shipping.png` · `logistics-dock.png` · `export-pallets.png`

### Zaroori baatein
- Naam **hu-ba-hu** same — sirf apni photo ka content badlein, naam nahi.
- Agar aap ki photo ka extension alag hai (jaise glove PNG hai `.jpg` ki jagah),
  koi baat nahi — bata dein, main site ko us extension par point kar dunga.
- Upload ke baad website khud nayi photos dikhane lagegi.
