# ⬆️ SAARI IMAGES YAHAN DAAL DEIN

Aap apni saari images (50–60, jitni bhi hon) **isi ek folder** mein upload kar dein.

- ✅ Koi bhi naam chalega (IMG_1234.jpg, glove1.png, factory.jpg — kuch bhi)
- ✅ Koi bhi format: JPG / PNG / WEBP
- ✅ Tarteeb ki fikar na karein

Upload ho jaane ke baad bata dein — Claude har image dekh kar website mein
sahi jagah (logo, factory, har glove type, certification, waghera) khud set
kar dega, sahi naam ke saath.

> Tip: ek saath multiple images select kar ke "Upload files" mein drag kar dein.
