# Required images

|---|---|---|---|
| hero-factory.jpg | Hero banner | 1920x1200 | Wide factory/press floor shot, dark-toned or will be overlaid with a dark gradient |
| why-blackforgex-factory.jpg | Why BlackForgeX | 900x1100 | Factory floor or production team at work |
| gallery-factory-floor.jpg | Factory Gallery | 1200x1200 | Wide factory floor shot |
| gallery-printing-machine.jpg | Factory Gallery | 800x600 | Screen printing press/machine close-up |
| gallery-pantone-matching.jpg | Factory Gallery | 800x600 | Pantone swatch book / color matching station |
| gallery-print-inspection.jpg | Factory Gallery | 800x1200 | QC inspector checking a printed garment |
| gallery-ink-mixing.jpg | Factory Gallery | 800x600 | Ink mixing lab |
| gallery-finished-garments.jpg | Factory Gallery | 800x600 | Folded/packed finished garments |
| quality-control-inspection.jpg | Quality Control section | 900x1100 | Inspector checking print registration |

Until these files are added, browsers will show the alt text in place of each image — the layout, captions and hover effects work either way.
