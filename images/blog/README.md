## Notes

- `embroidery-logo-stitching.jpg` shows placeholder text ("YOUR LOGGO") and a garbled machine brand — fine for a generic illustration, but avoid it where it would read as a real customer job.

- In WordPress, paste the alt text into the media library "Alternative Text" field when uploading.
