# BLACKFORGEX — Content Briefs

Upload page content briefs here (like the Screen Printing brief), one file per page:

- Format: `.md` (preferred), `.docx`, or `.txt`
- Naming: match the page slug — e.g. `about-us-brief.md`, `cut-and-sew-brief.md`, `jackets-brief.md`
- Competitor screenshots for a page can also go here: `about-us-competitor-1.png`, etc.

Claude Code reads briefs from this folder and builds the page using that exact content, following the master prompt's brand system, SEO/schema rules, and no-header/no-footer rule.

If there is no brief for a page, Claude writes original copy from the master prompt's company background instead — so briefs are optional, but they give you full control over the wording.
